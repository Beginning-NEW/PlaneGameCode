## 低成本方案判定

- 推荐的 GitHub Actions + Docker Compose + 既有 Nginx + `/healthz` 组合满足本次单服务演练，且不要求额外平台采购；GitHub 的免费/含额条件仍须由计费管理员核验，不能从本地仓库推断。
- Let’s Encrypt 可避免付费证书成本；开源 Docker Engine/Compose 与 Nginx 可避免软件订阅，但服务器容量、日志保留和 Docker Desktop 合规性必须单独核验。
- 不采用 K8s、Jenkins、Nacos、Apollo，避免在没有相应规模/多服务需求时引入额外算力、运维、升级、备份、监控与潜在托管/支持费用。

## 完成时的成本 Go / No-Go

**推荐：成本条件性 Go，付费扩张 No-Go。** 在以下条件同时成立时，允许继续零增量的上线演练：不采购任何资源；GitHub 用量已确认不会产生费用；服务器不扩容；复用既有 DNS；使用免费 Let’s Encrypt；不接入付费监控或其他 SaaS。任一条件不成立时，成本立场立即转为 **No-Go，待 CEO 再审批**。
